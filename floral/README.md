# Floral papers

The 146 papers from [Floral-Deck](https://github.com/szk5334/Floral-Deck) (73 full-colour clippings and their 73 sun prints), resized for the player's Floral visuals.

- `full/` 720×1008 JPG, the picture the visuals melt (`c-` full colour, `s-` sun print)
- `thumb/` small JPGs for the Menu → Visuals → Pictures list
- `floral.json` the list the player reads: id, title, kind, ink, source and Smithsonian page

All CC0 1.0 (public domain), from the Smithsonian's Open Access collection (Cooper Hewitt, Smithsonian Design Museum). No credit required; sources are kept in `floral.json`.
